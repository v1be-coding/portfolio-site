# Portfolio site

Emiliano's personal site: a bio, Emiliano's Experience, and the V1be Coding Series. Series-wide terms are in the [series glossary](https://github.com/v1be-coding/series/blob/main/GLOSSARY.md).

## Language

**Experience**:
One role Emiliano has held, as the home page shows it: company, title, dates and what the work was. Most of this work is private, so an Experience describes it but never links to it.
_Avoid_: Job, position, work history entry, project

**Engagement**:
One product Emiliano worked on within a single Experience, such as one client's platform during a consulting role. It has its own name and dates.
_Avoid_: Project, client, assignment

**Series**:
V1be Coding as a whole, as this site presents it: what it is, how it works, and its Episodes.
_Avoid_: Showcase, project

**Episode**:
One app in the Series, with its own page here. It has the same meaning as in the series glossary. This site is Episode 0.
_Avoid_: Project, build

**Scorecard**:
An Episode's results, as the series rules define them (time to green, attempts, tests passing on attempt 1, build cost, model used, what the spec missed, frozen tests that turned out wrong), shown on its Episode page. An Episode that hasn't finished has none yet.
_Avoid_: Stats, metrics, results

**Chat**:
The AI assistant a visitor opens from the tab in the corner of every page. It answers questions about Emiliano using only the site's own content.
_Avoid_: Ask, bot, chatbot, assistant
